A modern, feature-rich digital services platform with AI integration, community features, and e-commerce capabilities.

## Tech Stack(some are to be applied later, but to have a complete view on the project...)

| Technology | Purpose |
|-----------|---------|
| **React 18** | Frontend UI framework for building interactive components |
| **React Router v6** | Client-side routing for seamless page navigation |
| **Tailwind CSS** | Utility-first CSS framework for rapid UI styling |
| **Framer Motion** | Animation library for smooth, engaging transitions |
| **Vite** | Lightning-fast build tool and dev server |
| **Lucide React** | Icon library for clean, scalable icons |
| **Radix UI** | Accessible component primitives for UI building |
| **React Markdown** | Markdown parsing and rendering support |
